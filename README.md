# Uso
1. correr descarga.ipynb y descargar los datos de la EPH (bases individuos y hogares)
2. ir a https://www.indec.gob.ar/ftp/cuadros/sociedad/serie_cba_cbt.xls para descargar la serie historica de canasta basica total
3. del archivo, quedarse con las columnas A y D de la pestaña CBA-CBT y exportarlas a un csv
4. guardar el csv en la carpeta data
5. Ejecutar descarga.ipynb
6. Ejecutar limpieza.ipynb
